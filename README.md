# 🧰 skills-collection

> **428 скиллов** из **10 источников** (9 проверенных репозиториев + собственные сборки) — подключаются к этому чату **одной фразой** и остаются с вами во всех проектах.

Скилл — это файл `SKILL.md` с инструкцией для агента: когда ваша задача совпадает с описанием скилла, агент подхватывает его и работает по нему. Коллекция собрана и проверена вживую в этом чате: все 428 скиллов установлены, папки с коллизиями имён переименованы (`test-driven-development--addyosmani`, `handoff--mattpocock` и т.п.).

## Подключить — одна фраза в чате

Напишите агенту в любом чате на этом сайте:

> **Установи скиллы из https://github.com/Genocide12/skills-collection**

Что произойдёт: агент склонирует репозиторий и скопирует скиллы в `/home/z/my-project/skills/` — с этого момента они доступны во всех чатах. Устанавливать достаточно один раз: файлы в рабочей области сохраняются между сообщениями.

Полезные варианты той же фразы:

| Фраза | Что сделает агент |
| --- | --- |
| «Установи скиллы из …/skills-collection» | все 428 скиллов |
| «Установи скиллы из …/skills-collection — только superpowers и ECC» | только выбранные источники |
| «Обнови скиллы из skills-collection» | перекачает свежие версии из 9 исходных репозиториев и допушит в этот репозиторий |
| «Покажи, какие скиллы установлены» | выведет список из manifest.json |

## Ручная установка (резервный вариант)

```bash
git clone https://github.com/Genocide12/skills-collection.git
cd skills-collection
./install.sh                  # авто: в чате → /home/z/my-project/skills/, иначе → ./skills/
```

Флаги:

```bash
./install.sh --target DIR     # свой каталог
./install.sh --only superpowers,ECC   # только выбранные источники
./install.sh --list           # показать источники и количество скиллов
```

Перезаписываемые папки автоматически бэкапятся в `<каталог>-backup-<дата>`.

## С чего начать: мой топ-15

**Дизайн интерфейсов** — подключать, если делаете веб-страницы:
`taste-skill` (арт-дирекшн для лендингов), `impeccable` (полировка UI), `hallmark` (дизайн новых страниц), `frontend-a11y` (доступность).

**Процесс разработки** (superpowers — золотой стандарт):
`brainstorming` → `writing-plans` → `executing-plans` — цикл «идея → план → выполнение»; `test-driven-development`; `systematic-debugging` — дисциплина поиска бага вместо хаотичных правок; `verification-before-completion` — проверка перед «готово»; `subagent-driven-development` и `dispatching-parallel-agents` — параллельная работа сабагентов.

**Качество и безопасность:**
`security-audit` (Cloudflare), `code-review` (Matt Pocock), `performance-optimization`, `debugging-and-error-recovery`, `security-and-hardening`.

**TypeScript / фронтенд-стек:**
`typescript-patterns`, `react-patterns`, `nextjs-turbopack`, `vite-patterns`, `spec-driven-development`.

## Как это работает в чате

- Каждый скилл — папка `skills/<имя>/` с `SKILL.md`: внутри короткая шпаргалка (name, description в заголовке) и сама инструкция со ссылками на вспомогательные файлы.
- При старте сессии агент видит список установленных скиллов и их описания; когда задача совпадает с описанием — он читает `SKILL.md` целиком и следует ему. Описания специально написаны так, чтобы «включаться» на нужные запросы.
- ECC — не список «наизусть», а энциклопедия: просто назовите тему (postgres, kubernetes, django, логистика) — нужные скиллы подхватятся по описанию.
- Файлы обычные markdown, поэтому та же коллекция подойдёт и любому другому агенту, который читает `SKILL.md`.

## Структура репозитория

```
skills/<имя-скилла>/SKILL.md   # сами скиллы (428 папок) + вспомогательные файлы
manifest.json                  # [{folder, skill, source, description}, ...]
INDEX.md                       # полный каталог по источникам
install.sh                     # установщик
```
