# 🧰 skills-collection

> **12 мега-скиллов под все задачи** — дистилляты 354 коллекционных + 39 платформенных скиллов. Агент читает один файл по типу задачи вместо сотен описаний.

Скилл — это файл `SKILL.md` с инструкцией для агента. Раньше коллекция состояла из 354 отдельных скиллов: агенту приходилось ориентироваться в сотнях пересекающихся описаний. Теперь каждое большое направление работы сведено в один файл-дистиллят: только железные правила, типовые ошибки, шаблоны и чек-листы из всех исходных скиллов. Исходники никуда не делись — они лежат в `skills/` для глубокого погружения.

## Подключить — одна фраза в чате

> **Установи мега-скиллы из https://github.com/Genocide12/skills-collection**

Агент склонирует репозиторий и скопирует 12 папок из `mega/` в `/home/z/my-project/skills/` — с этого момента они доступны во всех чатах. Файлы в рабочей области сохраняются между сообщениями.

## Ручная установка

```bash
git clone https://github.com/Genocide12/skills-collection.git
cd skills-collection
./install.sh            # мега-скиллы (12 файлов) — режим по умолчанию
./install.sh --full     # полная коллекция: все 354 исходных скилла
```

Флаги: `--target DIR` (свой каталог), `--only superpowers,ECC` с `--full` (только выбранные источники), `--list` (источники и количество). Перезаписываемые папки бэкапятся в `<каталог>-backup-<дата>`.

## Структура репозитория

```
mega/<NN-имя>/SKILL.md         # 12 мега-скиллов (дистилляты) — главное
skills/<имя-скилла>/SKILL.md   # 354 исходных скилла (архив для глубокого погружения)
manifest.json                  # машиночитаемый список коллекции
INDEX.md                       # каталог: мега-скиллы → задачи → состав
docs/index.html                # сайт-каталог с поиском
install.sh                     # установщик: mega (по умолчанию) / --full
```
