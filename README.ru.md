# skills-collection

**Десять скиллов, которые покрывают всё, что делает ИИ-агент** — один `SKILL.md` на область, от веб-интерфейса до продакшен-инцидентов.

Скилл — это один файл `SKILL.md` с инструкциями для агента: железные правила, типичные ошибки, шаблоны команд и чек-лист перед сдачей работы. Вместо сотен пересекающихся скиллов агент грузит один файл на тип задачи и находит ровно те правила, что нужны.

## Установка — одна фраза в чате

> **Установи скиллы из https://github.com/Genocide12/skills-collection**

Агент сам склонирует репозиторий и скопирует десять папок в свою директорию скиллов — с этого момента они доступны в каждом чате.

Ручная установка:

```bash
git clone https://github.com/Genocide12/skills-collection.git
cd skills-collection
./install.sh                 # сам определит директорию скиллов агента, иначе ./skills
./install.sh --target DIR    # любая директория на ваш выбор
```
